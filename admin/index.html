Редактор сайта

Меняй тексты и фото прямо на странице. Чтобы правки сохранялись на GitHub, редактору нужен ключ доступа к репозиторию сайта. Его нужно создать один раз, и хранится он только в этом браузере.

  1. Открой создание ключа на GitHub. Название, срок и нужное право уже заполнены.
  2. В разделе Repository access выбери Only select repositories и отметь albalaeff.github.io.
  3. Убедись, что в Permissions у Contents стоит Read and write, и нажми Generate token.
  4. Скопируй ключ (он начинается с github_pat_) и вставь его ниже.
