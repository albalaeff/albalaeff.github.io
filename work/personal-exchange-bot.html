Cash exchange between people, without the guesswork.

Swapping cash with another person can beat a bank or an exchange office. The hard parts are finding someone nearby, agreeing on a fair rate and trusting a stranger. Personal Exchange Bot handles all three inside Telegram.

It works with 156 currencies in 10 countries, from Czechia to Thailand, and speaks English, Ukrainian and Russian.

How a deal works

  1. Post an offer

    “I give 1,000 EUR, I want 24,500 CZK.” Market and exchange-office rates help you set a fair price.

  2. Get responses

    Other people accept your rate or suggest their own.

  3. Choose one

    You pick a response. A private deal chat opens between the two of you.

  4. Meet and rate

    You agree on a meeting point on the map, exchange cash, confirm and rate each other.

The bot never holds money. It runs the deal: relays messages in the deal chat, collects confirmations and ratings.

Trust is the product

People meet strangers to exchange cash. These are the safety features I built.

  • Encrypted deal log. Every deal chat is logged, and the log is encrypted.
  • Account checks. Phone verification, Telegram account age, and lookups in the CAS and LOLS spam databases.
  • Weighted reputation. A reputation score built from weighted ratings.
  • Risk score. A risk score that alerts moderators.
  • Complaints. Users can file a complaint about a deal.

Quality

4,808

automated tests in pytest. Every pull request has to pass all of them.

Four kinds of tests

  • Unit tests for the core logic.
  • Integration tests against a real PostgreSQL database.
  • End-to-end tests that run the bot, the worker and the admin together.
  • Property-based tests with Hypothesis, for inputs nobody thought of.

Every pull request, in order

  1. ruff
  2. mypy
  3. pytest
  4. gitleaks

Linting, type checks, the full test suite and a secret scan run on GitHub Actions. I set up the test infrastructure underneath: database fixtures, a test bench for the bot and the end-to-end tests.

What I built

  • Interface and design. Admin redesign, mobile version, System and Stats sections, ban management, and the Android admin app.
  • Trust and safety. Encrypted deal log, account checks, weighted reputation, risk score, complaints.
  • Rates and languages. Rate sources, reading amounts like “1000 euro” or “€1000” from text, Ukrainian and the language packs.

How I work with agents

  • Small tasks, clear criteria. One change per pull request, through automated checks.
  • Environment checks. Tooling that checks an agent’s environment before it works.
  • A map of every screen. All 173 screens in one place, so agents and people can find their way around.
  • Automatic handoff. Work passes automatically from one agent session to the next.
