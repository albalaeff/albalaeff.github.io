Personal Exchange Bot

Rubles for local currency, person to person. A safer alternative to exchange chats, with a rate you can check.

Read the case study Open in Telegram

Banks won’t take rubles

Since the 2022 sanctions, most banks and exchange offices in Europe no longer exchange rubles. Yet many Russians live abroad and need local money, like Czech koruna.

Chats are full of scammers

So people swap in Telegram chats, typing “I’ll swap this much for that much” by hand, with scammers among them.

Changers push the rate

Money changers in those chats inflate the rate and set the trend for everyone else.

The bot turns this into a clear process: structured offers, rates to compare, checked accounts and ratings.

Built in a team of two.

The idea and the original spec came from my teammate. I turned the spec into a working product in two days, then kept building.

Version one in two days

On 30 September and 1 October I built the first working version end to end: database, offer feed, responses, deals and ratings, notifications, moderation, a web admin with two-factor login, Docker and tests.

Interface and design

Bot flows and the admin panel: the redesign, the mobile version, the System and Stats sections, ban management, and an Android admin app in Kotlin with Jetpack Compose.

Trust and safety

An encrypted log of every deal chat, phone and Telegram account checks against the CAS and LOLS spam databases, weighted reputation, a risk score that alerts moderators, and deal complaints.

Rates and languages

Market rates from ExchangeRate-API, exchanger rates from BestChange, Revolut and Wise for comparison. The bot reads amounts written as text, like “1000 euro” or “€1000”. I also added Ukrainian and the language packs.

Test infrastructure

I laid the groundwork for testing: database fixtures, a test bench for the bot, and end-to-end tests that run the bot, the worker and the admin together.

Tooling for AI agents

Environment checks, a map of every screen, and automatic handoff between agent sessions, so each new session picks up exactly where the last one stopped.

On Personal Exchange Bot every change runs through the same loop: one GitHub issue, one coding agent, one fresh session. People stay in the loop through the issue thread.

    Show the exchanger rate on the offer card

    Open an issue

    Every task starts as a GitHub issue. Its labels set the model and the effort, using Claude Code’s own values.

  2. Session manager

    #58sonnet, highrunning
    #59haiku, lowqueued

    Start an agent

    A session manager runs the issue watcher and starts one headless Claude Code agent per issue, each in its own git worktree.

  3. AIAgent commented on #57

    Market rate3.64
    Exchangers3.81

    Before any code, the agent posts how it understood the issue, with sample screens where relevant.

    2. Cover the rate row with tests

    Build
